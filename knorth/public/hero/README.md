# Hero Face Assets

Place the following assets in this directory:

## Required Files
- **face.png** - Base face, eyes open, strand removed, 1563x1563, transparent background
- **bleft.png** - Right eye closed (wink), strand removed, same canvas dimensions
- **bright.png** - Left eye closed (wink), strand removed, same canvas dimensions
- **strand.png** - Isolated hair strand only, transparent background, same canvas, aligned to sit exactly where it was removed from the base face

All assets should be:
- 1563x1563 canvas size
- Transparent background (PNG)
- Properly aligned so they layer seamlessly
